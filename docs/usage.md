# 使用指南

[返回项目首页](../README.md)

桌面窗口支持拖动边缘或角落调整大小，也可使用系统窗口按钮最大化或进入全屏。macOS、Windows 和 Linux 的最小内容尺寸均为 560 × 500，工作台会随窗口宽度调整布局。

1. 点击左栏顶部“新增项目”，在弹窗中选择或输入项目/仓库目录，识别并添加具体 Flutter 应用包。导入列表和上次选中的项目自动保存，关闭或更新应用后恢复；保存/读取失败会提示并提供重试，缺失目录仍保留在列表中。旧版本未保存的导入列表需要重新导入一次。
2. 点击左栏项目行，右栏默认显示平台、运行模式、设备和入口；设备选择旁可刷新设备或启动模拟器。“高级设置”默认折叠，展开后可配置项目 SDK 和启动参数，检查 SDK 位于路径输入框右侧。附加已有应用时在高级设置填写 VM Service URI。
   Git 仓库项目会在左栏显示当前分支，点击配置页项目标题下方的分支名可选择并切换已有本地分支，旁边的刷新图标可更新仓库信息；分支入口固定在标题区，正文滚动时仍可使用。识别包含普通 `.git` 目录、worktree 的 `.git` 文件和祖先目录中的仓库；非仓库项目不显示分支选择。分支信息在添加、恢复和选择项目时读取，外部切换后可手动刷新；同一仓库的项目共享切换结果。分离 HEAD 和尚无提交的仓库有对应提示。切换失败保留当前状态并显示原因，不会强制覆盖未提交改动，也不会自动 stash、拉取或创建远程分支。分支切换后重新检查项目 SDK，已运行会话继续使用原有 SDK。
3. 点击配置页标题栏右侧“启动会话”后，会话显示在项目下方。项目行右侧的启动按钮复用该项目上次提交的配置，未提交的草稿修改不影响快捷启动。折叠高级设置保留已填写的参数。
   同一标题栏的“构建”按钮打开打包窗口，可独立选择构建平台 / 产物类型和预设，无需选择设备。内置 Android APK / App Bundle、iOS / IPA、Web 和桌面 Release 预设；还可选择 AAR、Flutter 资源包，新增、编辑或删除预设。参数使用 JSON 字符串数组，例如 `["--release", "--flavor", "production", "--dart-define=API_URL=https://example.com", "--target", "lib/main_prod.dart"]`，窗口展示实际 `flutter build` 命令。构建复用当前项目 SDK 偏好，运行配置的设备和参数不影响打包。
   构建配置只读展示目标项目的 `version+build_number`，例如 `1.2.3+45`。版本读取自项目 `pubspec.yaml` 的 `version`，按当前参数中的 `--build-name` 和 `--build-number` 覆盖后预览；缺失的字段显示未配置，读取失败可重试。任务列表和详情保留创建任务时记录的版本，后续修改项目文件或构建参数不改变既有任务的版本记录。
   执行时显示构建状态及最近日志，可以停止构建，也可随时关闭窗口继续后台运行。左侧固定的“构建任务”入口显示进行中数量；点击任务可重新查看进度、日志、错误和产物目录，或停止任务。切换项目或查看运行会话不会停止构建；详情窗口关闭后停止读取日志，后台仅刷新任务摘要。近期任务保留在本次应用运行内，最多32条；退出应用会确认并停止仍在进行的构建。
   成功后自动在 Finder、Windows 文件资源管理器或 Linux 文件管理器打开产物目录，也可手动重新打开。可填写绝对路径或相对于项目的产物目录来指定成功后打开的位置；实际改变输出位置需通过对应目标支持的构建参数配置。自动打开失败会显示提示并保留构建成功结果。具体目标是否可构建由宿主和所选 SDK / 工具链决定。
4. 点击会话查看右栏日志、源码与调试等功能区；暂停、热重启、热重载和停止位于右栏顶部右侧，按模式和实际能力开放。
5. 日志按批和分页获取；源码只读。基础调试面板可设置断点并发出调用栈、变量及求值请求，当前需要查看协议结果中的 thread/frame/reference ID。
6. 会话的“DevTools”页提供原生网络面板。已连接 VM Service 的 Debug 会话打开页面后启用 HTTP profiling，默认每秒刷新；选择请求后，顶部固定显示地址、状态、耗时与响应大小，下方按“请求头 / 参数 / 响应”标签查看，默认选中参数。参数采用名称—值两列，Query 和 URL 编码表单按字段解码，重复参数保留，Query、表单字段及 JSON 请求正文中的对象和数组均支持逐节点展开/收起；响应页包含正文与响应头，JSON 响应同样支持嵌套节点展开/收起。各内容区可切换原始内容并复制，完整 URL 可单独复制；切换标签和刷新同一请求保留滚动位置与展示模式。支持搜索、暂停自动刷新和手动刷新；点击搜索框右侧的“清空”按钮可清空本地列表及选中详情，后续新请求仍会继续显示。
7. DevTools 页顶部可切换 Inspector、性能、CPU、内存和运行时日志。首次选择官方模块才启动当前会话 SDK 的 DevTools，页面跟随工作台主题；支持重新连接和失败重试，加载失败时可在系统浏览器中打开。模块切换复用服务与 WebView，切回网络、离开 DevTools 页、停止会话或退出应用时释放服务。Inspector 限 Debug，其余模块可连接 Debug / Profile；Release 不开放。断点和单步仍使用“源码与调试”面板。

官方模块通过稳定版 `flutter_inappwebview` 内嵌：macOS 使用 WKWebView，本机已验证；Windows 使用 WebView2，需要运行库，缺失时提供明确提示和浏览器恢复入口，实机仍待验收。Linux 当前显示内嵌不可用提示，可手动打开浏览器，但不计为应用内集成完成。Windows 构建需将 NuGet CLI 加入 PATH。当前 macOS 内嵌页尚未接管页面生成文件的下载，导出请使用模块工具栏的“在浏览器中打开”入口。

网络面板复用当前 SDK 调试适配器的 VM Service 接口，无需向目标项目加入 Dio 拦截器。支持 `dart:io` 及接入 `http_profile` 的 HTTP 请求，Flutter Web、Profile、Release 和未接入 profiling 的原生网络请求不在本版范围。只采集 profiling 启用后的请求；暂停按钮暂停页面刷新，目标 profiling 仍继续记录。页面最多保留500条请求，正文预览与复制上限为128 KiB，超限会明确提示；multipart 暂展示原始文本，二进制正文只显示说明。网络 RPC 的 DAP 响应超过16 MiB时，只报告本次读取失败并继续保留调试会话。

左栏底部“应用设置”提供外观和全局默认 SDK。浅色、深色可在侧栏或设置页切换，偏好自动保存；切换保留当前会话和未提交配置。SDK 可选择目录、验证并保存或清除。项目 SDK 优先使用独立配置、FVM 和项目设置；异常时自动回退到全局 SDK，并显示实际路径与原因。没有项目 SDK 配置时，全局默认值优先于环境自动发现。更改默认值用于下一次检查和启动，不改变已运行会话。

导入项目、上次选择、全局默认 SDK、主题偏好、构建预设、项目运行草稿、上次启动配置、多套命名配置、自动热重载开关及编辑器配置已持久保存；历史会话、构建与测试任务仅保留在本次应用运行内，重启不会自动启动任何任务。设置文件位置：macOS `~/Library/Application Support/flutter_dev/settings.json`、Windows `%APPDATA%/flutter_dev/settings.json`、Linux `$XDG_CONFIG_HOME/flutter_dev/settings.json`（未设置时使用 `~/.config`）。项目与其他设置共用原子写入和串行锁，项目保存最多500条，整个设置文件上限1 MiB。

Rust 是唯一权威会话状态。会话通过 DAP 调用 Flutter SDK；核心不重复执行 `flutter run`。launch 会话负责清理其进程树，attach 默认通过 `terminateDebuggee: false` 解除附加。macOS 关闭窗口保留会话，退出应用时确认并清理。

macOS 从 Finder/Dock 启动时，SDK 子进程会自动补上已安装的 Homebrew 工具目录，使 Flutter 能找到 CocoaPods 和 Homebrew。原有 PATH 顺序保留；如果在运行配置中显式设置 PATH，则按该值执行，需要自行包含所需工具目录。


## 运行配置与自动热重载

项目配置页的“当前草稿”入口可选择该项目的已保存配置。“另存为”保存一套命名配置，旁边菜单可更新、重命名或删除；例如分别保存开发环境和测试环境。设备、平台、模式、入口、SDK 选择、Flavor、dart-define、环境变量、工具参数、noDebug 和附加 URI 都会恢复。编辑草稿会延迟合并保存，编辑中的环境变量和参数原文也会保留；更新命名配置需要点击“更新当前配置”。保存失败会显示提示并提供重试，磁盘旧设置不会被覆盖。左栏快捷启动仍使用上次提交的配置，重新解析当次所选 SDK。

“自动热重载”按项目启用并保存，对该项目已有及后续可热重载的 Debug 会话生效。同一规范化项目路径共享 Rust 系统文件监听，正常情况下每8秒扫描校验漏事件，系统监听不可用时每2秒轮询兜底并尝试恢复。连续保存合并到最后一次变更至少600ms后处理；会话繁忙时保留待处理版本，重载期间的新保存会在完成后补执行。原生事件与扫描结果去重，同一版本编译失败不会反复重试；修正源码后保存可再次触发。

监听范围包含应用 Dart 文件和实际解析的本地路径依赖，包括目录外、传递及覆盖依赖和 workspace 本地包。依赖配置更新后重新发现监听范围；配置暂时缺失、写入未完成或扫描失败时保留上次可用范围和基线。新增或修改依赖声明仍需自行执行 `flutter pub get`，本工具不会自动解析依赖、热重启或重新构建原生代码。构建、缓存、Git、Pods、node_modules等目录不参与扫描，目录内符号链接不递归跟随；显式本地依赖根规范化后单独监听。单次扫描最多20000个目录项、10000个Dart文件、32层目录，源码内容读取最多64MiB；单份依赖配置最多2MiB，最多2000个已解析包、512个本地包。容量限制、监听与扫描错误记录在会话日志。

离开页面不会关闭监控；关闭开关清除该会话积压任务，重新开启建立新基线；会话停止后释放订阅，最后一个订阅离开后释放项目监听。Profile / Release、能力明确不支持热重载的适配器不执行；noDebug 需要适配器明确支持。热重载沿用当前会话 DAP，不启动额外的 `flutter run`。

## 日志与编辑器

iOS Debug / Profile 新启动会话（含 noDebug）按所选 SDK 的设备信息开启日志隔离。每个会话分配独立 VM 服务端口，并从自己的 VM Service 订阅 Dart stdout / stderr；普通 DDS 连接会补发其保留的启动日志。SDK 的设备日志按 `Runner` 等可执行文件名筛选，可能混入其他项目和无前缀的多行续行，因此不将其 stdout / console 作为会话日志；启动状态改从 DAP 进度事件展示，工具 stderr 和编译错误仍保留。设备原生 stdout 不在这个隔离通道中。

自定义 `--device-vmservice-port` 和 `--host-vmservice-port`（或旧名 `--vm-service-port`）应使用同一非零端口；缺省或零会自动分配。本工具内活动会话不复用 VM 端口，DDS 另用独立端口；需要固定 DDS 端口时可传 `--dds-port`。重复、冲突或无效的端口会报错。停止、启动失败或会话结束会释放逻辑端口预约和日志连接，不保留额外监听进程。

设备识别失败会让启动明确失败，不退回可能混流的通道。Dart 日志连接失败或断开时记录 warning，需重新启动会话恢复，不自动重连重放历史。单条 WebSocket 消息上限1 MiB，按 stdout / stderr 分别保留不完整 UTF-8 字节；完整行入库，无换行内容在换行、达到64 KiB或连接结束时刷新。日志仍受核心及界面原有总容量限制。Release、附加会话和非 iOS 目标保持原日志实现，本次隔离修复未覆盖这些场景。

日志工具栏可切换错误筛选及暂停/恢复跟随；暂停跟随仍采集新输出。识别到 Dart 堆栈中的 `package:`、`file:///`、绝对或相对文件坐标后，点击行旁的源码位置按钮打开编辑器，打开失败可重试，日志原文仍可选择和复制。

“应用设置”中的“源码编辑器”可保存可执行文件路径/命令与 JSON 参数数组。默认命令为 `code`，参数为 `["--goto", "{file}:{line}:{column}"]`，需要该命令在应用环境中可执行，也可填写编辑器命令的绝对路径。路径、行、列按占位符替换为独立进程参数，普通文件路径中的空格和百分号保留，`package:` 依据项目真实 package_config 解析。未安装对应编辑器或命令失败会提示原因。

## 网络检索与复制

请求列表支持 HTTP 方法和状态多选，与 URL/方法/状态搜索叠加；“重置筛选”恢复全部。清空会移除全部本地请求与详情，保留筛选条件。右键请求可按需读取并复制 POSIX shell 格式的 cURL 命令，保留原始 URL、重复 Headers 和完整文本正文；不会执行该命令。发送尚未完成、正文未采集、二进制或超限时明确提示，避免复制不完整请求。

响应页的搜索覆盖格式化或原始正文，显示匹配数量并高亮；JSON 折叠内容也参与搜索。各 JSON 内容分区提供“全部展开”“全部收起”，原有独立节点开关及每树200个可见节点、12层上限保留。搜索、筛选和折叠不改变复制内容及预览上限。

## 测试面板

配置页标题栏的试管图标可在未启动应用时打开项目测试；运行会话的“测试”页也可进入。先显示 `test/` 下实际 `_test.dart` 文件，再由 `flutter test --machine` 的运行事件展示真实测试名称。支持全部、单文件、已发现单个测试、精确失败重跑及停止，并展示通过/失败/跳过计数、错误和分页输出。测试使用项目所选 SDK，独立于普通应用会话；关闭面板后继续运行，重新打开可恢复本次应用运行内的最近任务，退出应用会确认并清理进程。

当前提供宿主执行的单元测试和 Widget 测试，不提供测试源码静态解析、设备 integration_test 调度或覆盖率视图。每项目同时最多一轮测试，最多保留16轮历史；单轮结果最多5000项、结果字符串4MiB、日志2MiB，超限会报告失败或保留截断说明，不假装全部成功。失败重跑最多5000个选择，总请求不超过2MiB；实际参数/路径仍受平台执行规则约束。Windows/Linux 尚未实机验收。

## 快捷键

底部键盘图标可查看快捷键。操作遵循当前所选会话、模式、能力及繁忙状态。

| 快捷键 | 操作 |
| --- | --- |
| F5 | 启动所选项目，或继续已暂停的会话 |
| Shift + F5 | 停止所选会话 |
| ⌘ / Ctrl + R | 热重载 |
| ⌘ / Ctrl + Shift + R | 热重启 |
| ⌘ / Ctrl + F | 聚焦当前日志或网络搜索 |
| ⌘ / Ctrl + Alt + ↑ / ↓ | 切换项目 |
| Ctrl + Tab / Ctrl + Shift + Tab | 切换会话 |
| ⌘ / Ctrl + 1–4 | 切换日志、源码调试、DevTools、测试页 |
